- 原工作区中 Learning 目录的既有 Git 改动未处理。

## 关键行为验收

| 场景 | 预期行为 |
| --- | --- |
| 无 API Key 启动 | 健康检查、Schema、文档列表可用；调用模型时清楚报错 |
| 普通启动 | 不加载本地 ML 库和模型 |
| 原生与框架输出 | 普通/流式/结构化均可用，结果与调用信息结构一致 |
| 空知识库 | 返回明确的无知识状态，回答不假装有依据 |
| 首次入库 | 自动创建新集合与片段，无需先执行检索 |
| 重复与版本替换 | 去重；新版本成功前保留旧版本；失败不覆盖 |
| 删除中断 | 删除中的版本不可检索，允许重试清理 |
| 取消入库 | 等待线程当前批处理退出，不发布半成品 |
| SQL 越界 | 写操作、系统表、跨库查询、多语句被拒绝 |
| SQL 昂贵查询 | 执行预算中断，而不只是截断返回行 |
| Agent | 有证据的工具循环与追问；无依据不能 success |
| 月报 | 独立聚合，排除取消订单与待退款，不重复累计 |
| 追踪 | 重启后保留记录，父子调用关联，未知用量不写零 |
| 批量评估 | 单例失败继续，结果即时保存，有版本信息 |

## 验证层次

pytest 验证确定性机制和边界；前端 Node 测试验证 SSE 分片、UTF-8、异常与结束事件；构建验证页面编译；scripts.smoke 使用真实服务验证少量端到端路径。

48 条 Golden Cases 是后续持续评估的起点，不代表已经对每个模型和每个业务场景完成质量认证。生成质量、检索相关性和因果判断仍需要持续评估与人工核对。
